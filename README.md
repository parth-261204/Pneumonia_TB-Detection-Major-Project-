# TB & Pneumonia Detection using Deep Learning and Explainable AI

A production-ready deep learning system for detecting Tuberculosis and Pneumonia from chest X-ray images using ensemble learning and Grad-CAM visualization [web:1][web:6][web:10].

## Features

- **Multi-Model Ensemble**: Combines MobileNetV3, EfficientNetB0, DenseNet121, and ResNet50
- **Transfer Learning**: Pre-trained on ImageNet, fine-tuned on medical data
- **Explainable AI**: Grad-CAM heatmaps for visual interpretation
- **Automated Reports**: PDF diagnostic reports with visualizations
- **Production Ready**: Comprehensive logging, metrics, and error handling
